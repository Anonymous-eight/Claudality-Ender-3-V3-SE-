Contributing to the Claudality Open-Source Illustration Library

Thank you for contributing to the illustration library for the Claudality Open-Source DIY Fabrication Guide.

This repository does NOT contain the book itself.

Its purpose is to build an original, legally reusable illustration library that will be integrated into future editions of the book.

---

Current Illustration Roadmap

The current edition contains 12 chapters.

Illustrations are requested only for these chapters.

Appendices are NOT included because they will be published separately as fold-out engineering posters.

Image Requirements

Images should be:

- Original artwork
- Original CAD renders
- Original photographs
- Creative Commons licensed
- Public Domain

Preferred format:

- SVG
- PNG
- PDF (Vector)

Minimum resolution:

- 2000 pixels

Preferred background:

- White

Preferred style:

- Technical engineering illustration

---

Copyright Rules

Do NOT submit:

- Copyrighted manual images
- Commercial book figures
- Watermarked images
- Images with unknown licenses

Only submit:

- Your own work
- Public Domain material
- Creative Commons licensed material
- Material with explicit permission for reuse

---

Naming Convention

Please name files using the figure number.

Examples:

Fig-2.3-X-Axis-Assembly.png

Fig-4.7-Wiring-Diagram.svg

Fig-7.2-Bed-Leveling.pdf

---

Pull Request Checklist

Before submitting:

✓ Correct figure number

✓ Correct title

✓ High resolution

✓ Correct license

✓ Original or reusable image

✓ Technical accuracy
