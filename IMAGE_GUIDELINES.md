# Claudality Open-Source Illustration Project

# IMAGE_GUIDELINES

## Purpose

This document defines the image quality, formatting, and licensing requirements for all illustrations submitted to this repository.

Following these guidelines helps maintain a consistent, professional illustration library for future editions of the Claudality Open-Source DIY Fabrication Guide.

---

# Accepted Image Types

Contributors may submit:

- Original technical illustrations
- Original CAD renders
- Original photographs
- Public Domain images
- Creative Commons images that allow commercial reuse
- Open-source technical diagrams

---

# Do NOT Submit

Please do NOT submit:

- Copyrighted book illustrations
- Images copied from commercial manuals
- Watermarked images
- Screenshots from copyrighted websites
- Low-resolution images
- AI-generated images that infringe third-party copyrights

---

# Preferred Formats

- SVG (Preferred)
- PNG
- PDF (Vector)
- High-quality JPG (only if necessary)

---

# Minimum Quality

- Minimum width: 2000 pixels
- Sharp and readable
- Clean white background whenever possible
- No compression artifacts
- No visible editing marks

---

# Illustration Style

Preferred illustrations should be:

- Technical
- Clear
- Educational
- Professionally presented
- Suitable for engineering publications

Avoid:

- Decorative artwork
- Promotional graphics
- Meme-style images
- Excessive visual effects

---

# File Naming

Whenever possible, use the corresponding figure number.

Examples:

Fig_4_01.png

Fig_5_07.svg

Fig_10_03.pdf

---

# Before Submitting

Please verify that:

- The illustration matches the requested figure.
- The file is high quality.
- The licensing requirements are satisfied.
- The image follows these guidelines.

---

Thank you for helping build the official Claudality Open-Source Illustration Library.
