Claudality Open-Source Illustration Project

Welcome

Thank you for your interest in contributing to the official illustration library for the Claudality Open-Source DIY Fabrication Guide.

This repository does NOT contain the book itself.

The purpose of this repository is to build a high-quality, legally reusable collection of technical illustrations that will be used in future editions of the book.

---

Our Goal

We are building an illustration library covering topics including:

- Open-source 3D printer architecture
- Ender-3 V3 SE mechanical platform
- BIGTREETECH SKR Mini E3 V3.0 integration
- Klipper firmware
- Raspberry Pi host configuration
- Motion system
- Belt routing
- Linear rails
- Dual Z-axis upgrades
- CR-Touch installation
- Extruder assembly
- Hotend components
- Wiring diagrams
- Cable management
- Printer calibration
- Klipper configuration
- Maintenance procedures
- Troubleshooting
- Safety illustrations

Image Quality

Please submit illustrations suitable for professional technical publishing.

Preferred formats:

- SVG
- PNG
- PDF (vector)

Minimum resolution:

2000 pixels

Preferred background:

White

Preferred style:

Technical engineering illustrations.

---

Copyright Policy

Please DO NOT upload:

- Copyrighted book images
- Screenshots copied from commercial manuals
- Watermarked images
- AI-generated images that violate third-party copyrights

Only submit:

- Your own work
- Public Domain material
- Properly licensed Creative Commons content
- Material with explicit permission for reuse

Repository Workflow

1. Choose an open illustration request.

2. Prepare the image.

3. Verify licensing.

4. Submit a Pull Request.

5. Wait for review.

6. Approved figures will become part of the official illustration library.
